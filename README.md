# LTX-2.5 Video Worker (RunPod Serverless)

Text-to-video and image-to-video generation with the uncensored merged
build of Lightricks **LTX-2.5** (ChrisColeTech/LTX-2.5-uncensored-v1.1-FP8:
Eros10 NSFW LoRA + DMD distilled LoRA + IC-LoRAs baked into the distilled
weights), via ComfyUI v0.46.1, on a single RTX 4090 (24GB). Videos come
with synchronized audio generated by the model itself.

Image: `ghcr.io/zk3u5pp-ops/ltx25-worker:latest` (built by GitHub Actions
on every push to `main`).

## How it works

- ComfyUI v0.46.1 (Comfy-Org) with the **official LTX-2.5 blueprints**
  ("Text to Video (LTX-2.5)" / "Image to Video (LTX-2.5)") converted to
  API format — see `workflow_t2v.json` / `workflow_i2v.json`. All nodes
  used are in ComfyUI core; no custom nodes are installed.
- `handler.py` (RunPod SDK) receives a job, patches the workflow JSON,
  queues it on the local ComfyUI server (127.0.0.1:8188), polls
  `/history`, and returns the MP4 as base64.
- `start.sh` downloads the ~43GB model set from HuggingFace on first
  boot (with aria2 + SHA-256 verification), then starts ComfyUI and the
  handler. If a network volume is attached at `/runpod-volume`, models
  are stored there and shared across workers.

## Model files (auto-downloaded on first start)

Source: `ChrisColeTech/LTX-2.5-uncensored-v1.1-FP8` on HuggingFace
(`split/` subdirectory; ungated) for the transformer, text encoder and
VAEs. The prompt-enhancer E2B encoder comes from `Comfy-Org/gemma-4`
and the spatial upscaler from the `comfyicu/LTX-2.5` mirror (the
official `Lightricks/LTX-2.5` repo is gated).

| File | Size | Purpose |
|---|---|---|
| `diffusion_models/ltx25_uncensored_v1.1-fp8_scaled.safetensors` | 21.47 GB | Merged transformer (FP8, Eros10 + DMD + IC-LoRAs baked in) |
| `text_encoders/gemma4_12b_ltx25_uncensored-int8.safetensors` | 13.16 GB | Uncensored text encoder (int8) |
| `text_encoders/gemma4_e2b_it_int8_convrot.safetensors` | 5.20 GB | Prompt enhancer (int8, from `Comfy-Org/gemma-4`, ungated) |
| `vae/ltx25_uncensored_video_vae.safetensors` | 1.47 GB | Video VAE (byte-identical to the official one) |
| `vae/ltx25_uncensored_audio_vae.safetensors` | 0.36 GB | Audio VAE (byte-identical to the official one) |
| `latent_upscale_models/ltx-2.5-latent-spatial-upscaler-x2-bf16-1.0.safetensors` | 1.00 GB | Spatial upscaler (first pass runs at half res) |

No distilled LoRA is needed: the distilled transformer works standalone.
Prompt enhancement (`TextGenerateLTX2Prompt`, using the Gemma 4 E2B file)
is disabled by default — the workflow's `ComfySwitchNode` is lazy, so the
enhancement branch never executes. The E2B file must still be present:
ComfyUI validates every loader's filename at queue time, and the
workflows won't queue without it, even with enhancement off.

## API

### Text-to-video

```json
{
  "input": {
    "prompt": "A cat walks across a sunlit garden",
    "width": 1280,
    "height": 720,
    "duration": 5,
    "fps": 24,
    "seed": 12345
  }
}
```

### Image-to-video

Add `image_base64` (the first frame). Optional I2V knobs:
`i2v_strength_first` (default 0.7), `i2v_strength_second` (default 1.0),
`img_compression` (default 18).

### Common optional fields

`negative_prompt`, `frames` (overrides `duration`;
frames = duration*fps + 1), `timeout` (default 840s).

Limits: duration max 5s (10s clips can OOM the VAE decode on 24GB);
width/height are snapped to the nearest multiple of 64 (256–1280). The
/64 snap is required: the first pass runs at half resolution and the
latent size is floored to a multiple of 32, so a 720 request yields a
704px file. Snapping keeps the reported size equal to the actual file.

### Response

```json
{
  "ok": true,
  "video": "<base64-encoded mp4>",
  "seed": 12345,
  "mode": "t2v",
  "width": 1280, "height": 720, "duration": 5, "fps": 24,
  "frame_count": 121,
  "timings": {"elapsed_s": 152.4}
}
```

Failures return `{"ok": false, "error_code": ..., "error_message": ...,
"retryable": bool}`.

## RunPod endpoint settings

- GPU pool: ADA_24 (RTX 4090) only
- Container disk: 120GB (image ~10GB + models ~43GB + headroom)
- initTimeout: 3600s (first-boot model download)
- Job timeout: 900s
- min workers 0 / max workers 3, FlashBoot OFF

## Cost estimate (RTX 4090 serverless, $1.10/hr)

~2–3 min per 5s 720p clip on a warm worker → roughly $0.04–0.06 per
clip. Cold starts add the model-load time (from local disk, ~1–2 min)
and, on first boot only, the ~43GB download.
